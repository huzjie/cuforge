# 架构设计

## 分层

```
┌─────────────────────────────────────────────────────┐
│  Serving (FastAPI) / CLI / SDK                      │  接入层
├─────────────────────────────────────────────────────┤
│  Engine (CuForge 门面)                               │  编排层
├──────────────┬──────────────┬───────────────────────┤
│  VeriGen     │  Agent       │  RLVR                 │  能力层
│  任务合成     │  智能体运行时  │  在线强化学习          │
├──────────────┴──────────────┴───────────────────────┤
│  Desktop Env (虚拟桌面环境)                           │  环境层
├─────────────────────────────────────────────────────┤
│  Core (实体: Task/Action/Observation/Trajectory...) │  模型层
└─────────────────────────────────────────────────────┘
```

## 核心闭环（一次 episode）

```
Task ──reset──▶ DesktopEnv ──obs──▶ Policy ──action──▶ DesktopEnv
                                      ▲                  │
                                      └──── obs ─────────┘
                 ...直到 done / 超时
终态 ──Verifier──▶ Reward(result/process/format)
```

## 关键设计决策

1. **可验证优先**：任务合成时绑定验证器，环境终态确定性打分，这是 RLVR 的前提。
2. **确定性环境**：`virtual` 后端完全 deterministic，同种子可复现，便于评测与调试。
3. **策略可插拔**：`Policy` 抽象支持脚本基线 / LLM 决策，RLVR 通过 `update` 钩子适配。
4. **零依赖内核**：核心闭环仅用 stdlib；FastAPI/YAML 作为可选依赖。
