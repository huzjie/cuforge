# ScaleCUA 论文解读（本项目技术来源）

## 一句话

清华大学与 Z.AI 提出 **ScaleCUA**：用 VeriGen 在真实桌面容器里**规模化合成可验证 GUI 任务**，
再配合**前沿采样**与**视觉上下文切分**，把开源计算机使用智能体做到 OSWorld 68.7%、
ScienceBoard 54.0%（9B 模型，刷新开源 SOTA）。

## 四个核心问题

论文把 GUI 智能体训练拆成四条缩放维度，ScaleCUA 是唯一**四项全勾**的方案：

| 维度 | 既往方法 | ScaleCUA |
|---|---|---|
| 可验证任务能否规模化 | 只覆盖一两点 | VeriGen 程序化合成 + 确定性判题 |
| 采样是否有效 | 全成功/全失败学不到信号 | 前沿采样 + 组内相对比较 |
| 能否大规模在线 RL | 受限于样本量 | RLVR（可验证奖励的在线强化学习） |
| 多轮训练是否高效 | 样本数随交互轮数直线涨 | 视觉上下文切分控制 token |

## 47 步 GNOME 主题安装的例子

论文用一个「装 GNOME 主题」的例子说明难点：逛主题站 → 下载解压 → 终端安装 →
gsettings 切换，中间点错一次目录，后面几十步往往白烧。GUI 强化学习难的根因是：
这类题通常只有指令和环境，没有数学题那种现成判题器。VeriGen 解决的正是「造可验证题」。

## 本项目的落地映射

| ScaleCUA 概念 | cuforge 实现 |
|---|---|
| VeriGen 可验证任务合成 | `cuforge/verigen/`（6 模板 + 11 验证器） |
| 桌面容器环境 | `cuforge/env/`（virtual 后端，可切 docker） |
| 计算机使用智能体 | `cuforge/agent/`（运行时 + 策略 + 视觉上下文） |
| RLVR 在线强化学习 | `cuforge/rl/`（GRPO + 前沿采样 + 三路奖励） |
